\section{Core Differential Kinematics}
The circular-arc state estimation model is formulated as:
\begin{equation}
\Delta s = \frac{\Delta s_L + \Delta s_R}{2}, \quad \Delta \theta = \frac{\Delta s_R - \Delta s_L}{W}
\end{equation}
\begin{equation}
x_{k+1} = x_k + \frac{\Delta s}{\Delta \theta} \big(\sin(\theta_k + \Delta \theta) - \sin\theta_k\big)
\end{equation}
